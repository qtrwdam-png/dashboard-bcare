## 2. إصلاح مشكلة تحديث الوقت لبطاقات النفاذ والراجحي

### المشكلة
- بطاقة النفاذ وبطاقة الراجحي تستخدمان نفس الوقت
- يتم تحديث وقت بطاقة واحدة عند ملء الأخرى

### الحل
استخدام حقول منفصلة لكل بطاقة

### 2.1 بطاقة النفاذ (nafad)

#### أ) عند إرسال رمز التأكد (nafad_modal)
**الموقع:** `components/visitor-details.tsx` - case "nafad_modal"

```javascript
updates = {
  nafadConfirmationCode: nafadCode,
  nafadConfirmationCodeUpdatedAt: getCurrentTimestamp(),  // جديد
  nafadUpdatedAt: getCurrentTimestamp(),                  // جديد
  nafadUpdatedAtTimestamp: getCurrentTimestamp(),        // جديد
  currentStep: "nafad",
  currentStepUpdatedAt: getCurrentTimestamp(),
};
```

#### ب) عند الإرسال من حقل الإدخال (handleSendNafadCode)
**الموقع:** `components/visitor-details.tsx` - سطر ~198

```javascript
await updateApplication(visitor.id, {
  nafadConfirmationCode: nafadCode,
  nafadConfirmationStatusUpdatedAt: getCurrentTimestamp(),
  nafadUpdatedAt: getCurrentTimestamp(),  // جديد
});
```

#### الحقول المستخدمة:
| الحقل | الوصف | النوع |
|-------|-------|-------|
| `nafadConfirmationCode` | رمز التأكيد | string |
| `nafadConfirmationCodeUpdatedAt` | وقت إرسال الرمز | number |
| `nafadUpdatedAt` | آخر تحديث لبطاقة النفاذ | number |
| `nafadUpdatedAtTimestamp` | timestamp إضافي | number |

#### الأرقام في bubbles:
```javascript
timestamp: visitor.nafadUpdatedAt || visitor.updatedAt,
```

### 2.2 بطاقة الراجحي (rajhi)

#### عند الموافقة/الرفض/إرسال رسالة
**الموقع:** `components/visitor-details.tsx` - case "rajhi"

```javascript
case "rajhi":
  if (action === "approve") {
    await updateApplication(visitor.id, {
      rajhiOtpStatus: "approved",
      rajhiOtpStatusUpdatedAt: getCurrentTimestamp(),
      rajhiUpdatedAt: getCurrentTimestamp(),           // جديد
      rajhiUpdatedAtTimestamp: getCurrentTimestamp(), // جديد
    });
  } else if (action === "reject") {
    await updateApplication(visitor.id, {
      rajhiOtp: "",
      rajhiOtpStatus: "rejected",
      rajhiOtpStatusMessage: message,
      rajhiOtpStatusUpdatedAt: getCurrentTimestamp(),
      rajhiUpdatedAt: getCurrentTimestamp(),           // جديد
      rajhiUpdatedAtTimestamp: getCurrentTimestamp(), // جديد
    });
  } else if (action === "message") {
    await updateApplication(visitor.id, {
      rajhiOtpStatus: "message",
      rajhiOtpStatusMessage: message,
      rajhiOtpStatusUpdatedAt: getCurrentTimestamp(),
      rajhiUpdatedAt: getCurrentTimestamp(),           // جديد
      rajhiUpdatedAtTimestamp: getCurrentTimestamp(), // جديد
    });
  }
  break;
```

#### الحقول المستخدمة:
| الحقل | الوصف | النوع |
|-------|-------|-------|
| `rajhiOtpStatus` | حالة OTP | "approved" | "rejected" | "message" |
| `rajhiOtpStatusUpdatedAt` | وقت تحديث الحالة | number |
| `rajhiUpdatedAt` | آخر تحديث لبطاقة الراجحي | number |
| `rajhiUpdatedAtTimestamp` | timestamp إضافي | number |

#### الأرقام في bubbles:
```javascript
timestamp: visitor.updatedAtTimestamp || visitor.rajhiUpdatedAt || visitor.updatedAt,
```

## 4. تقييد الدول (allowedCountries)

**الملف:** `components/settings-modal.tsx` (سطر 370-445)

### الوصف:
> تحكم في الدول التي تسمح لها بالوصول إلى موقعك الإلكتروني للتعزيز الأمان.
> يمكنك إضافة أكثر من دولة. وسيمنع الوصول من أي دولة غير موجودة في القائمة.

### الحقل:
```typescript
allowedCountries: [] // قائمة الدول المسموحة
```

### ملاحظة:
> هذه الميزة موجودة في الإعدادات لكنها **غير مطبقة** في موقع العملاء بعد.
> الدالة `isCountryAllowed` موجودة لكن لا تُستخدم.

## 5. ملاحظات مهمة

### redirectPage vs currentStep
| الحقل | الاستخدام | النظام |
|-------|---------|--------|
| `redirectPage` | الصفحات الحديثة | Modern pages |
| `currentStep` | الصفحات القديمة | Legacy pages |

لوحة التحكم ترسل **كلا الحقلين** لضمان التوافق.

### ترتيب الأرقام في bubbles
```javascript
// للنفاذ:
timestamp: visitor.nafadUpdatedAt || visitor.updatedAt,

// للراجحي:
timestamp: visitor.updatedAtTimestamp || visitor.rajhiUpdatedAt || visitor.updatedAt,
```
